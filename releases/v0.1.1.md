# InkLeet v0.1.1

本版集中改进刷题编辑体验、原生登录和 Rust 调试数据展示。仍处于早期版本阶段，不表示已达到成熟 IDE 的完整兼容性与稳定性。

## 下载
- Windows x64：setup EXE 或 MSI，任选一种。
- macOS Intel x86_64：DMG。不是 Apple Silicon 原生构建。
- Linux x86_64：tar.gz，解压后使用 start.sh；需要 Ubuntu 24.04 / Mint 22 系列依赖，不是通用静态包。
- SHA256SUMS 与 RELEASE_MANIFEST.json 包含安装包校验值、源码版本、构建来源与验收记录。

## 相比 v0.1.0
- Rust Map 展开后直接成对显示实际键和值，支持已识别的嵌套集合；修复 Windows CodeLLDB 格式化器路径转义，减少冗余说明文字。
- “原始结构”按钮移到变量名旁，避免右侧原生滚动条抢占点击；保留无法安全识别结构时的原始查看方式。
- 原生二维码登录、二维码刷新及可选的会话保存；保留用户主动选择的官方网页登录路径。
- 题面阅读宽度与字号控制、编译诊断、Vim K 文档导航和带语法高亮的悬浮信息。
- 编辑器与源码阅读器的实现跳转、引用与跳转历史；补充题目官方样例和完整题面/解答复制。
- 可视化与 JSON 设置编辑、字体及语义配色、快捷键设置；修复干净文档误报未保存、窗口关闭、终端高度和保存状态问题。

## 限制与升级
- Windows/macOS 安装包未签名，macOS 未公证；不要关闭系统安全保护。
- Windows/macOS 交互安装、升级、卸载、完整原生 GUI，以及 Ventura、真实原生输入法与长期性能仍有未覆盖场景。
- Rust 集合识别是有边界的，未知/自定义类型可退回原始结构；本版不声称所有 Rust 类型都可结构化展示，也未纳入独立开发中的 Option 增强。
- 工具环境隔离不是安全沙箱，只运行可信代码。诊断用 snippet 特性不进入安装包。
- 升级前备份解答、笔记和应用数据并关闭旧版本，避免多个版本同时写入同一份数据。
- Android 与 macOS ARM 不属于此次附件范围。
