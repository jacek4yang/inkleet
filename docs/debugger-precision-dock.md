# 调试位置与可折叠面板检查点

基于 InkLeet b375dbca43e8e8324cf14224e3cb984740717f14。Lithe 参考固定为 6210013d06e1410c7bcbb1949e1ff16ea8deae15；本检查点为 CodeMirror 原生重新实现，没有复制 Monaco/Swift 组件或增加插件链。

## 本轮机制
- 统一操作 SVG 的 24×24 坐标、1.65 描边与图标按钮；保留用户批准 C 品牌和有 CC0 来源的 LeetCode 图形。
- 本地运行/调试和在线用例/结果各有纵向分隔条，支持指针捕获、取消、键盘上下/Home/End、最近高度本机记忆。隐藏保留组件、输入、监视与会话，不发送停止命令。
- 留出编辑区空间，窗口缩小时限制实际高度，不覆盖用户偏好高度。
- DAP frame column/endLine/endColumn 从原始响应传到 CM。有效范围、只有列、只有行分别展示；首列缺少范围时保守为行。UTF-16 边界不按 Tab 宽度或字符数推测。
- 真实执行顶帧与查看调用帧采用不同底纹。源码改变、不同文档、失效暂停时清除位置。
- 后端用真实规范化源码路径核对所属文件，拒绝把同名外部文件标到当前源码。
- 只有调试器实际声明支持时显示选择函数步入；原始目标 ID 转发到 stepIn，空结果保留普通步入。请求受 session/epoch/frame 身份保护。

## 当前能力边界
- debugpy 1.8.22 可能提供范围，也可能默认首列；不能承诺每个表达式暂停。
- Delve 1.27.2 当前 stackTrace column=0，按行显示；不支持 stepInTargets。
- CodeLLDB 1.12.3 提供实际列，没有结束范围；智能步入取决于 LLDB 接口能力，同名调用可能去重。
- Java bootstrap 尚无完整 AST 调用目标解析，保持该能力关闭；Java 表达式求值依然不可用。
- 本轮没有宣称与 JetBrains 全功能等价。条件断点、异常过滤、修改变量、逆向执行等需独立功能和原生验证。

## 验收
1. 打开题目，本地面板；拖上边缘、方向键调整，再收起/恢复，输入和高度不丢。
2. 运行/暂停中收起，恢复后仍为同一个会话，没有重复启动/停止。
3. 同时展开在线结果与本地面板，小窗口仍能编辑；分隔条可键盘操作。
4. 同行两处不同 adapter column/range 必须更新；调用者帧不能冒充执行 PC。
5. 更改源码、切语言、旧目标回复均不能保留旧标记或目标。
6. 支持的 adapter 选择一个函数步入；不支持时无空按钮，不伪造目标。
7. 分别记录六语言真实 stackTrace/capability，浏览器 fixture 不代表真实适配器能力。

## 执行指针补充
用户明确要求动态小标识：新增行号旁 SVG 执行箭头，以及有可靠列数据时的行内小三角指针。每次暂停随位置更新，不做推测性游走或连续动画。查看调用帧用蓝灰色箭头，真实执行用金色；无列的适配器只画行级箭头。
