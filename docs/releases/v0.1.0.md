# InkLeet v0.1.0 — first preview

Release candidate preparation. Publication is not complete until a verified GitHub Release exists.

## Scope
- Local-first LeetCode practice workspace using Tauri 2, React, CodeMirror 6 and Rust.
- Named solutions per problem and language, notes, editable cases and local execution.
- Language-service completion, diagnostics, rename preparation/preview, references and recursive source reading.
- Explicit save/format workflow, unsaved recovery and conflict protection.
- Vim controls, searchable settings, language formatting overrides and Tab display width.
- Basic debugger controls and Rust logical collection views.

## Downloads
The release targets macOS Intel x86_64 DMG, Windows x64 setup EXE/MSI, and Linux x86_64 tar.gz.
All four files must come from the same verified source commit. Record the full commit, source workflow and SHA-256 hashes with the assets.
Windows users should choose EXE or MSI, not install both formats together.

## Important limitations
This is a preview, not a claim of mature IDE parity or full daily-use acceptance.
Windows and macOS packages are unsigned; macOS is not notarized. Do not disable operating-system security protections.
macOS Intel is not an Apple Silicon build. Declared minimum versions are package metadata, not tested compatibility promises; Ventura has not completed end-to-end acceptance.
Linux packages target Ubuntu 24.04 / Mint 22-style dependencies, not every Linux distribution.
Windows/macOS interactive installation, upgrade, uninstall and GUI behavior need separate acceptance.
Real-account login, online Run/Submit and native IME are not fully qualified.
Diagnostic-only snippet features are excluded from distributable builds.
Managed downloaded language tools are isolated from normal PATH use, not a security sandbox; run only trusted code.

## Upgrade precautions
Back up source, notes and application data before upgrading. Close older InkLeet instances and do not run multiple versions against the same data.
Application identity and data location remain unchanged.
Older previews may reject new nondefault settings fields; downgrade compatibility is not promised.

## Acceptance gate
Before publishing, confirm exact-source frontend typechecking, unit tests and browser regression; required native regression; all platform build/inspection jobs; and all artifact hashes.
A green package build is not a substitute for the limitations above.
