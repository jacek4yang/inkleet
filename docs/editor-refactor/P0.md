## P0 机制与来源
之前的提交 956399a0 / 69573059 已补充 CM 原生 Tab 补全/缩进、Shift+Tab、明确四空格缩进和 body tooltip portal。dfca6d6 增加原生键盘验证。本分支继续补充 Backspace、多光标、撤销及精确空白检查，不把已有提交归称为移植。

参考 [use-monaco-editor-settings.ts](https://github.com/1lck/Lithe-IDEA/blob/6210013d06e1410c7bcbb1949e1ff16ea8deae15/windows/tauri/src/features/editor/engines/monaco/use-monaco-editor-settings.ts)：
- 它从集中配置读取 tabSize、字体、换行等，并用细粒度 selector 避免订阅无关设置。
- 分类 B：集中配置设计适用；Monaco 配置对象不能直接用于 CodeMirror。
- 本轮使用 CM 原生 indentUnit、tabSize、keymap、tooltips 和 setTabFocusMode；不是复制 Lithe 代码。
- 动态配置通过 Compartment、设置持久化、语言覆盖进入 P2；当前硬编码只是 P0 的明确默认值，不宣称设置系统完成。

CM 原生 deleteCharBackward 已按缩进单位处理前导空白，因此本轮先新增真实断言，不重复实现删除算法。P0 不改变保存、账户、在线提交或 LSP 后端。

## 回归方法
前端 tests/ui.mjs：
1. Python 中键入函数头，Enter 后键入 return，精确比较四空格。
2. Shift+Tab / Tab 验证当前行和选中块。
3. Backspace 删除一个缩进单位，Undo 恢复。
4. Ctrl+D 多选两个同名标识符、同时输入和 Undo。
5. Escape 后 Tab 可离开编辑器，避免键盘焦点陷阱。
6. 真实补全 DOM 的命中测试确认未被相邻面板遮挡，Tab 接受候选；原有 Escape、迟到结果、重命名和引用测试保留。

Linux tests/native_smoke.py：
1. 实际 WebKitGTK、真实私有 Pyright，无 mock IPC。
2. 键盘 Enter / Shift+Tab / Tab / Backspace。
3. 行 textContent 精确比较空白，再逐字比较原生保存的 solution.py。
4. 保留完整六语言、恢复副本、外部文件冲突和公开中国站回归。
